# 仓库范围

此仓库只包含后处理源码、提示词、标签本体、测试和说明，不将原始数据与历史宽表复制入库。原下载器继续作为本机的数据获取工具，后处理在私有服务器执行。

项目不会自动恢复或启动先前停止的下载任务，也不依赖 Chrome 或图形界面。`prepare` 不调用模型；`demo` 明确使用规则基线和合成输入；`run --backend local` 才调用本地模型。

对外提交前检查 Git 的暂存文件清单，排除原始数据、处理输出、模型、环境、浏览器资料和凭据。`.gitignore` 是辅助措施，不替代对暂存内容的核查。

当前 GitHub 仓库创建和推送必须使用用户授权的账号。无凭据或连接器缺少创建仓库能力时，保留已经完成的服务器项目与 Git 提交，明确报告尚未发布，不能把计划中的地址当作实际已存在的仓库。
