# 本批数据如何流动

本批固定输入于2026-11-07，2026-11-10 05:56（北京时间）完成最终汇总。以下数量来自已完成批次，完整原文、原始文件和模型回复保留在私有环境。

## 三组守恒关系

```text
43,653,625 已知记录 = 27,792,348 显式排除 + 15,861,277 保留处理
15,861,277 保留处理 = 14,420,658 字段方案 + 1,440,619 复杂语义来源
 1,440,619 语义来源 =    388,349 不同内容代表 + 1,052,270 重复来源
```

388,349只表示语义通道去重后的代表数量。代表推理完成后，逐来源核对并回填到1,440,619条复杂来源，再与14,420,658条字段方案记录合并。最终15,861,277条台账按EXTRACTED 6,300,941、NO_EVENT 3,381,302、REVIEW 6,179,034分别保留状态。
