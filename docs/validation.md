## 读取器的真实回归

- 两份使用自定义 rdf:about 资源节点的 RDF，从旧版本的零记录恢复为 253 和 11 条，共 264 条。
- 一份约 107KB、15 条有效记录的 Excel 声明范围为 `A1:XDC1048542`。重置声明范围、按实际坐标读取后得到 15 行、6 列，约 2.155 秒；样本中的非空值与旧读取结果一致，虚假超宽标记消失。
- 全目录复核重新读取 XLSX，其他格式复用内容哈希核验过的缓存；总记录数和文件状态计数保持一致。初次扫描 1,485.96 秒，修复后的续跑 222.61 秒，**两者缓存条件不同，不作为冷扫描加速比**。
- XLSX 使用 reader-v3-xlsx-dimensions，其他格式继续使用 reader-v2；相应缓存按读取版本失效。过小范围也有回归检查，避免截断实际记录。

147 个文件级复核：76 个压缩包、41 个 PDF、8 个旧 Word、7 个 DOCX、3 个 RAR、3 个未知格式，以及 2 个 CSV、6 个 RDF、1 个 XLS 读取/结构异常。表头不确定、列宽异常等质量标记另存于卡片，成功解析不等于已解决这些问题。

## 模型与检查

实际环境：Python 3.10.22，RTX 4090，驱动 525.105.17，PyTorch 2.6.0+cu118，CUDA 11.8，Transformers 4.51.3，Accelerate 1.6.0，LM Format Enforcer 0.11.3。Qwen3-8B BF16 单卡运行，context=8192、max_output=2048、enable_thinking=false。权重共 16 个文件，约 16.40GB，私有目录保留哈希清单。

33 项 Python 检查在本地和服务器 Python 3.10 环境通过；6 项页面检查通过，wheel 构建及提示词/本体资源打包检查通过。检查包括格式伪装、工作表范围、RDF 节点、来源变化后缓存失效、原文引用、受约束的 ID/字段候选、失败拆分、复核导出、身份冲突、不同款项不误合并及重复运行。桌面和窄屏的展示区块完成浏览器检查。

`scripts/verify_local_model.py` 提供可重复的合成回归：相关文件保留、树木统计排除、检查合格不创建处罚、拟认定保留阶段，以及逐条状态覆盖。规则和本地模型路径均需明确标记，不能相互冒充。
