# 数据采集与安全控制

采集器独立于后续推理流程。本页说明本项目使用的下载策略，不把默认参数作为吞吐测试结果，也不表示官网承诺接受该频率。

| 困难 | 已采用的方法 | 可核对的产物 |
| --- | --- | --- |
| 数据集散布在详情页，附件入口动态变化 | 从官网导出目录；已有清单则复用，再解析各详情页的附件入口 | `catalog/datasets.json`、官网导出原件 |
| 同一内容组提供多种格式 | 按数据集、版本、名称分组，CSV 优先、XLSX 次之；不同分片和年份分别保留 | 任务清单与格式选择记录；文件名分组不证明内容完全相同 |
| 慢文件阻塞调度，过量请求又容易触发限制 | 导航与点击至少间隔 1 秒，默认最多同时接收 4 个附件；浏览器接手后继续调度，后台接收 | 下载状态、待验收文件；达到并发上限等待空位 |
| 网络中断、超时、格式错误 | 每轮后统一验收；第二、三轮只补失败项；跨运行累计最多 3 次总尝试 | `download-state.json`、`download-failures.csv/.json` |
| 中断后重复工作或误认文件成功 | 临时接收与最终目录分离，检查非空、常见错误网页、基本格式、大小与 SHA-256；续跑时核对本地文件与台账 | 文件大小、哈希、状态与失败原因 |
| 业务数据和登录信息的边界 | 登录会话保留在本地浏览器；后续明细与本地 Qwen 推理保留在私有环境；公开页只输出汇总、匿名样本及明确的结构示意 | 私有明细与公开展示分离 |

文件级续跑不是 HTTP 字节断点续传。接收中断的文件在后续尝试重新接收，不将部分文件冒充成功。登录、验证码与访问限制要求人工处理，暂停时保留工作目录。默认间隔不保证不会限流，应按实际网站提示降低频率或并发。

SHA-256 在这里用于本地落盘、恢复和传输一致性核对；如果源站未提供校验值，就不能声称已经证明与源站原件一致。基本格式检查也不代替业务内容质量审核。

本批固定输入含 5,200 份已接收附件；上游 22 个失败项在下载失败台账单列，不计入已成功输入。目录数据集数、附件数、展开后的逻辑文件数和业务记录数分别计量。

## 公开来源目录接口

`scripts/build_source_overview.py` 从本批官网 XLS 目录、下载目录清单及完成汇总生成 `showcase/assets/source-overview.json`。20 个主题按官网顺序展示，数量合计 4,710。每类不超过 10 个来源时全量展示，超过时按名称排序等距取 10 个，样本不是价值排名。所有链接均为官网公开数据集下载页；不公开带登录会话的附件请求 URL。

```bash
python scripts/build_source_overview.py \
  --snapshot-dir PRIVATE_SNAPSHOT --run-dir PRIVATE_COMPLETED_RUN \
  --batch-summary showcase/assets/gallery-data.json \
  --output showcase/assets/source-overview.json
```

首张卡片的文件名、扩展名、字段及高低相关性是用于解释异构结构的示意，逐行链接对应真实官网数据集，不能作为原附件摘录或模型筛选判定。数据数量采用 2026-11-07 的本批固定目录，不代表官网实时总数。
