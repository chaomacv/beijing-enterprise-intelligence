文件卡片优先的本地模型处理流程：扫描 → 筛选 → 保留文件入库 → 分块抽取 → 证据核验 → 企业关联 → 导出。

- 新增 `bank-data workflow`，流式生成工作表样本，筛选前不建立全量原始记录事实库；阶段缓存支持重复执行。
- 新增仅绑定本机的 Qwen3-8B 服务，使用 Transformers 与 JSON Schema 约束；服务失联时停止，保留进度。
- 修复伪装成 CSV 的 Excel、自定义 RDF 资源节点、非空未知 XML、UTF-16 与无后缀文件识别；Excel 过大/过小的声明范围改按实际坐标读取，来源变化重新核验缓存。
- 支持九类业务事件，保留拟议、撤销、移出等状态；事件可引用受校验的文件标题及本行主体。
- 复核记录完整导出，无效推理不污染缓存；信用代码冲突阻止合并，名称相似仅产生复核候选。
- 更新交互式 Project Page、部署说明、方法选择依据与验证记录；公开示例均为合成数据。

实测：5,200 个附件完成校验与全目录扫描；5,050 个生成文件卡片、147 个待复核、3 个为空。Qwen3-8B 已在私有 RTX 4090 上运行，完成合成回归与真实小样本闭环。33 项 Python 检查与 6 项页面检查通过；合并后的 main CI 成功才创建此 Release，并附可安装的 wheel 包。

全量 LLM 筛选/抽取、PDF/OCR、压缩包展开、超长记录分片和独立准确率评测不属于本次已验证结果。详细范围、残留复核及运行数据见 [验证记录](https://github.com/chaomacv/public-data-llm/blob/main/docs/validation.md)。原始附件、真实处理结果、权重与凭据均未发布。
